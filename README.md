# Vehicle-sales-revenue-dashboard
Excel-based vehicle sales and pricing analytics project

## Project Overview
This project focuses on analyzing vehicle market data using Microsoft Excel to identify pricing trends, revenue performance, and business insights.

The dashboard was created using pivot tables, charts, and KPI metrics to support data-driven analysis and reporting.

---

## Objectives
- Analyze vehicle pricing trends
- Evaluate brand-wise revenue contribution
- Study seller and transmission-based pricing patterns
- Visualize sales performance using dashboards

---

## Dataset Features
- Vehicle Name
- Year
- Selling Price
- Kilometers Driven
- Seller Type
- Transmission
- Ownership Information

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Dashboard Design
- Data Visualization
- Financial Analysis

---

## Key Insights
- BMW cars have the highest share of revenue						
- Porsche financial services has the highest average selling price
-	Average selling price of a less driven car is much higher than that of a more driven car
